# 测试说明

## 1. 主链路

1. 打开首页，意图保持「经营改善、估值合理、走势稳定」。
2. 点击「澄清意图并生成条件草稿」。
3. 期望：出现 3 个澄清问题；条件卡含营收同比 / PE(TTM) / 近20日波动率。
4. 点击「执行筛选」。
5. 期望：列表按入选 / 待确认 / 排除分组；每条含实际值、阈值、来源、时点、判定理由。
6. 在默认阈值下，至少有部分股票入选（如贵州茅台、海天味业等演示样本），部分被排除（如波动过高或增速不达标）。

## 2. 条件修改与名单进出

1. 完成一次筛选后，将「营收同比」阈值从 10 改为 20。
2. 再次执行筛选。
3. 期望：出现「条件变化影响」区块，列出新进 / 退出代码。

## 3. 数据缺失

1. 在结果中找到「数据缺失示例 / DEMO.MISS」。
2. 期望：状态为「待确认」，营收同比判定为缺失并说明原因，**不会**被标为入选。

## 4. 冲突边界

1. 将 PE 区间改为下限 40、上限 10。
2. 期望：条件区出现「冲突错误：PE 下限大于上限」。
3. 关闭全部条件启用开关 → 出现「未启用任何条件」错误级冲突。

## 5. 扶摇 / 接口异常

1. 不配置 `FUYAO_API_KEY`：结果数据模式为「演示数据」，universeNote 说明原因。
2. 配置错误 Key 或不可达 `FUYAO_BASE_URL`：`fetchNotes` 含失败原因并回退演示数据。

## 6. 合规边界

1. 页面页脚与结果区含免责声明。
2. UI 无「买入/卖出/目标价/必涨」类文案或操作。
